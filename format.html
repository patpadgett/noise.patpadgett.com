noise-song v1

NOISE saves a whole cabinet as one JSON file with the extension .noise.json. It is meant to be read by people and other programs, not only by NOISE. Nothing is compressed or obfuscated; audio is embedded as a base64 WAV data URI, which every browser can decode with decodeAudioData.

Top level

{
  "format": "noise-song",        // required, identifies the file
  "version": 1,
  "title": "HEARSE RIDE AT 2 A.M.",
  "author": "",
  "bpm": 136,                    // 60–200
  "swing": 0.08,                 // 0–0.5, fraction of a 16th added to odd 16ths
  "screw": 0,                    // -7..+3 semitones; pitches and slows every device
  "master": { "saturation": 0.4, "tone": 11000, "wow": 0.25, "hiss": 0.3, "level": 0.9 },
  "devices": [ ... ],            // see below
  "arrangement": { "bars": 16, "tracks": { "<deviceId>": [ block, ... ] } },
  "meta": { "created": "...", "saved": "...", "app": "NOISE Select-O-Matic", "url": "https://noise.patpadgett.com" }
}

Devices

Each device has an id, a type, its knob values in params, a muted flag, and one or more patterns.

{
  "id": "hearse",
  "type": "hearse",              // breaker | hearse | cathedral | preacher | carousel
  "params": { "decay": 0.9, "glide": 0.14, "coffin": 0.22, "tone": 900, "rumble": 0.35, "level": 0.9 },
  "muted": false,
  "patterns": [
    { "id": "patA", "name": "A", "steps": 32,
      "notes": [ { "s": 0, "n": 28, "l": 4, "v": 1 }, { "s": 14, "n": 28, "l": 2, "v": 1, "g": 1 } ] }
  ]
}
typewhat n meansparams
breakerdrum lane 0–7: KICK, SNARE, CLAP, HAT, OPEN HAT, RIM, TOM, CRASHmemphis, decay, level, tune[8] (semitones per lane)
hearseMIDI note (24–48 shown). g: 1 slides from the previous notedecay, glide, coffin, tone, rumble, level

Carousel audio

The carousel device carries its record inline. Slice boundaries are seconds into the WAV.

"audio": {
  "name": "RESAMPLE BARS 1–2",
  "origin": "lathe",             // baked | lathe | user | file
  "sampleRate": 44100,
  "duration": 3.53,
  "slices": [ { "start": 0, "end": 0.44 }, { "start": 0.44, "end": 0.88 }, ... ],
  "encoding": "wav/pcm16/base64",
  "wav": "data:audio/wav;base64,UklGRi..."
}

WAV is PCM 16-bit, stereo when the source is stereo and under 12 seconds, otherwise mono to keep files small. A file with "audio": null asks NOISE to bake its built-in resample on load.

Arrangement blocks

{ "id": "blk1", "bar": 4, "bars": 8, "pat": "patA" }   // play pattern patA from bar 4 for 8 bars

A pattern shorter than its block loops; a pattern longer than its block is cut off. Blocks on one track never overlap; NOISE trims or splits neighbours when you drop a new one.

Slice files

The LATHE's EXPORT SLICES writes a sibling format, noise-slices v1: the same audio object above at the top level, so the chop can be reused without the song around it.

Reading it elsewhere

To play the audio in any browser: strip the prefix up to the comma, base64-decode, and hand the bytes to AudioContext.decodeAudioData. To reconstruct timing: one step is 60 / (bpm × 2^(screw/12)) / 4 seconds; add swing × step to every odd step.
